## 🎯 **RESPUESTA A TUS DUDAS**

### **1. "¿Necesito nivel de dificultad?"**

**BETA:** No, ejercicios tienen dificultad mezclada (fácil/medio/difícil)
**PREMIUM:** Sí, AI ajusta automáticamente según progreso del niño

**Recomendación BETA:** 
- No añadir selector manual
- Los ejercicios ya tienen variedad
- Más simple = mejor

---

### **2. "¿Opción Test o Ejercicio?"**

**SÍ, vale la pena en BETA:**

```javascript
// Diferencia:
if (tipo === 'ejercicios') {
  mostrarExplicacion: true,
  mostrarRespuesta: despuesDeLeerla,
  objetivo: 'Aprender'
}

if (tipo === 'test') {
  mostrarExplicacion: false,
  mostrarRespuesta: solo al final,
  objetivo: 'Evaluar'
}
```

**Útil porque:**
- Test para simular examen del cole
- Ejercicios para practicar
- Mismos datos, presentación diferente
