## 📚 TIER 1: TAXONOMÍA PEDAGÓGICA DE ERRORES

### **Clasificación según la naturaleza del fallo**

| ID | Patrón de Error | Descripción | Gravedad | Icono |
|----|----------------|-------------|----------|-------|
| **EC** | Error Conceptual | Falta de comprensión fundamental del concepto | ⚠️ CRÍTICA | 🧠 |
| **EP** | Error Procedimental | Concepto correcto, fallo en la secuencia/algoritmo | 🟡 MEDIA | ⚙️ |
| **EAC** | Error de Aplicación/Contexto | No logra transferir conocimiento a contexto nuevo | 🔵 MEDIA-BAJA | 🎯 |
| **ETF** | Error Transversal/Forma | Error menor que no afecta el núcleo de la competencia | 🟢 BAJA | 📝 |

## 1️⃣ ERROR CONCEPTUAL (EC)

### **Definición:**
El estudiante no comprende la definición, principio o teoría fundamental. El conocimiento base es incorrecto o está ausente.

### **Ejemplos por Asignatura:**

| Asignatura | Ejemplo |
|------------|---------|
| **Matemáticas** | No sabe qué es un número primo o confunde área con perímetro |
| **Lengua** | No diferencia entre sujeto y predicado |
| **Ciencias** | Confunde fotosíntesis con respiración celular |
| **Sociales** | No comprende la diferencia entre monarquía y república |

### **Plan de Intervención:**
```
Prioridad: 1 (MÁX IMA)
Tipo: Refuerzo conceptual profundo
Método: Explicación desde cero con ejemplos visuales y manipulativos
Duración: Sesiones largas (45-60 min)
Frecuencia: Diaria hasta dominio completo
```

### **Mensaje al Estudiante:**
```
🧠 Error Conceptual

Tu error no es de aplicación ni de procedimiento. El problema está en la 
comprensión del concepto fundamental.

Tu respuesta: "5 + 3 = 7"
Respuesta correcta: "5 + 3 = 8"

Criterio LOMLOE afectado: MAT_PRI4_C1.1 - Resuelve problemas con operaciones básicas

📚 Plan de acción:
1. Revisa la definición básica de suma con tu profesor o padre/madre
2. Practica con ejemplos visuales (fichas, objetos)
3. No avances hasta dominar completamente el concepto
```

## 2️⃣ ERROR PROCEDIMENTAL (EP)

### **Definición:**
El estudiante comprende el concepto, pero comete errores en la secuencia de pasos, aplicación del algoritmo o técnica de resolución.

### **Ejemplos por Asignatura:**

| Asignatura | Ejemplo |
|------------|---------|
| **Matemáticas** | Usa la fórmula de Bhaskara correctamente pero se equivoca en la secuencia de operaciones |
| **Lengua** | Conoce las reglas de acentuación pero falla al aplicar el orden correcto |
| **Ciencias** | Sabe el método científico pero lo aplica en orden incorrecto |
| **Sociales** | Conoce los acontecimientos pero los ordena mal cronológicamente |

### **Plan de Intervención:**
```
Prioridad: 2
Tipo: Práctica de procedimientos
Método: Ejercicios paso a paso con supervisión, listas de verificación (checklists)
Duración: Sesiones medias (30-45 min)
Frecuencia: 3-4 veces por semana
```

### **Mensaje al Estudiante:**
```
⚙️ Error Procedimental

Tu error no es conceptual. Has identificado bien el concepto, pero el 
fallo está en el procedimiento o secuencia de pasos.

Tu respuesta: "El resultado de (5 + 3) × 2 = 5 + 6 = 11"
Respuesta correcta: "(5 + 3) × 2 = 8 × 2 = 16"

Criterio LOMLOE afectado: MAT_ESO1_C2.3 - Modelización y resolución de problemas

⚙️ Plan de acción:
1. Revisa los pasos del procedimiento uno por uno
2. Usa una lista de verificación (checklist) para la jerarquía de operaciones
3. Practica con ejercicios similares supervisados
```

---

## 3️⃣ ERROR DE APLICACIÓN/CONTEXTO (EAC)

### **Definicón:**
El estudiante domina el concepto y el procedimiento, pero no logra transferir ese conocimiento a un contexto nuevo o resolver problemas complejos.

### **Ejemplos por Asignatura:**

| Asignatura | Ejemplo |
|------------|---------|
| **Matemáticas** | Resuelve ecuaciones abstractas pero falla al aplicarlas a problemas de la vida real |
| **Lengua** | Conoce el registro formal pero no lo usa correctamente en un ensayo |
| **Ciencias** | Sabe la teoría pero no la aplica en experimentos prácticos |
| **Sociales** | Conoce los hechos históricos pero no los relaciona con el presente |

### **Plan de Intervención:**
```
Prioridad: 3
Tipo: Práctica contextualizada
Método: Problemas de aplicación en diferentes contextos, casos prácticos
Duración: Sesiones cortas-medias (20-30 min)
Frecuencia: 2-3 veces por semana
```

### **Mensaje al Estudiante:**
```
🎯 Error de Aplicación/Contexto

Tu error no es ni conceptual ni procedimental. El problema está en aplicar 
tu conocimiento a este contexto específico.

Tu respuesta: "No sé cómo calcular cuántos caramelos le tocan a cada niño"
Respuesta correcta: "Dividir 20 caramelos entre 4 niños = 20 ÷ 4 = 5 cada uno"

Criterio LOMLOE afectado: MAT_PRI5_C1.2 - Calcula porcentajes y aplica a situaciones reales

🎯 Plan de acción:
1. Practica con problemas de aplicación en diferentes contextos
2. Identifica qué conceptos usar en cada situación
3. Trabaja con casos prácticos de la vida real
```

---

## 4️⃣ ERROR TRANSVERSAL/FORMA (ETF)

### **Definición:**
Errores menores o formales que no afectan el núcleo de la competencia evaluada, pero sí la presentación o efectividad.

### **Ejemplos por Asignatura:**

| Asignatura | Ejemplo |
|------------|---------|
| **Matemáticas** | Error de cálculo aritmético simple, copia mal un número, ilegibilidad |
| **Lengua** | Error ortográfico simple que no era el foco del ejercicio |
| **Ciencias** | Nomenclatura incorrecta pero concepto correcto |
| **Sociales** | Fecha equivocada (1491 en lugar de 1492) pero contexto correcto |

### **Plan de Intervención:**
```
Prioridad: 4 (Baja)
Tipo: Atención a detalles
Método: Revisión, checklists, autocorrección
Duración: Sesiones cortas (10-15 min)
Frecuencia: Ocasional, cuando aparezca
```

### **Mensaje al Estudiante:**
```
📝 Error Transversal/Forma

Tu respuesta es fundamentalmente correcta, pero tiene un error menor 
de forma o presentación.

Tu respuesta: "Cristóbal Colón descubrió América en 1491"
Respuesta exacta: "Cristóbal Colón descubrió América en 1492"

📝 Consejo: Revisa tu trabajo con calma antes de entregarlo.
```

## 📊 GENERACIÓN AUTOMÁTICA DE FICHAS FOCALIZADAS

### **Uso del Análisis Histórico:**

Si el sistema detecta que un estudiante tiene:
- **Patrón recurrente:** EP (Error Procedimental)
- **En criterio:** MAT_ESO1_C2.3 (Resolución de problemas)

**El sistema genera automáticamente:**

```javascript
{
    tipoFicha: 'Refuerzo Procedimental',
    criterio: 'MAT_ESO1_C2.3',
    patron: 'EP',
    ejercicios: [
        // Solo ejercicios de procedimiento paso a paso
        // Sin contextos compl ejos (que serían EAC)
        // Sin teoría conceptual (que sería EC)
    ],
    formato: 'Guiado con checklist',
    dificultad: 'Progresiva',
    cantidad: 10
}
```

**Resultado:** Ficha ultra-focalizada en el problema específico del estudiante.

| Patrón Error | Frecuencia | Criterios Afectados | Competencias Impactadas |

| EC | 10% | MAT_PRI4_C1.1, LCL_PRI4_C3.1 | STEM, CCL |

### **Interpretación:**

Este estudiante:
- ✅ Comprende los conceptos (EC bajo: 10%)
- ⚠️ Tiene problemas de procedimiento (EP alto: 60%)
- ✅ Aplica moderadamente (EAC medio: 20%)
- ✅ Cuida detalles (ETF bajo: 10%)

**Diagnóstico:** "Necesita supervisión de procedimiento, NO refuerzo conceptual completo"

**Intervención:** Práctica guiada paso a paso con checklists, no explicaciones teóricas desde cero.

## 🔬 DETECCIÓN AUTOMÁTICA DE PATRONES

### **Algoritmo Simple:**

```javascript
function detectarPatronError(pregunta, respuestausuario, respuestaCorrecta) {
    // 1. Calcular similitud
    const similitud = calcularSimilitud(respuestaUsuario, respuestaCorrecta);
    
    // 2. Análisis por tipo de pregunta
    if (pregunta.tipo === 'concepto' && similitud < 0.3) {
        return { patron: 'EC', confianza: 0.85 };
    }
    
    if (pregunta.tipo === 'procedimiento' && similitud > 0.3 && similitud < 0.8) {
        return { patron: 'EP', confianza: 0.75 };
    }
    
    if (pregunta.tipo === 'aplicacion' && similitud > 0.4) {
        return { patron: 'EAC', confianza: 0.7 };
    }
    
    if (similitud > 0.8) {
        return { patron: 'ETF', confianza: 0.9 };
    }
    
    // Default
    return { patron: 'EC', confianza: 0.5 };
}
```
